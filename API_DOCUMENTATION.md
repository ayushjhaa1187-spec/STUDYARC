# SkillBridge Pro API Documentation

## Base URL
`/api`

## Authentication
Most endpoints require a Bearer token generated by Supabase Auth.
`Authorization: Bearer <JWT_TOKEN>`

## Endpoints

### 1. Auth & Profiles
- `GET /users/me`
  - **Headers**: Authorization required
  - **Returns**: User profile details including reputation and role.

### 2. Diagnostics
- `POST /diagnostic/evaluate`
  - **Headers**: Authorization required
  - **Body**: 
    ```json
    {
      "targetRole": "Full-Stack Developer",
      "weeklyHours": 10,
      "skills": ["HTML", "JS"],
      "experienceLevel": "beginner"
    }
    ```
  - **Returns**: AI evaluation, readiness score, and recommended journey.

### 3. Sprints & Tasks
- `GET /sprints/active`
  - **Headers**: Authorization required
  - **Returns**: List of active sprints with nested tasks.
- `POST /sprints/:sprintId/tasks/:taskId/complete`
  - **Headers**: Authorization required
  - **Body**: `{ "proofUrl": "https://github.com/..." }`
  - **Returns**: Updated task.

### 4. AI Coach
- `POST /coach/chat`
  - **Headers**: Authorization required
  - **Body**: `{ "sprintId": "uuid", "message": "I am stuck on task 2" }`
  - **Returns**: AI reply and saves history.

### 5. Portfolio
- `POST /portfolio/submit`
  - **Headers**: Authorization required
  - **Body**: 
    ```json
    {
      "sprintId": "uuid",
      "title": "My project",
      "githubUrl": "https://github.com/my/project",
      "description": "Desc"
    }
    ```
  - **Returns**: AI pre-check feedback and status.

### 6. Bookings & Payments
- `GET /mentors`
  - **Returns**: Verified mentors.
- `POST /bookings/create`
  - **Body**: `{ "expertId": "uuid", "slotTime": "2024-10-10T10:00:00Z", "couponCode": "ayush1187" }`
  - **Returns**: Razorpay order ID and booking reference.
- `POST /payments/webhook`
  - **Headers**: `x-razorpay-signature`
  - **Description**: Verifies signature and marks booking as paid.

### 7. Admin
- `GET /admin/metrics`
  - **Headers**: Authorization required (Admin only)
  - **Returns**: Revenue and user counts.
